# Gofile Bulk Downloader

A user-friendly, Python-based Gofile downloader with a desktop graphical interface.

## Features

- Download entire Gofile folders
- Support folder IDs and complete URLs
- Download videos only, photos only, or all files
- Recursive folder downloading
- Resume interrupted downloads
- Concurrent downloads with automatic retries
- Preview files before downloading
- Windows launcher for easy startup

## Installation

**Requirements:** Python 3.10 or newer.

1. Clone or download the repository.
2. Install dependencies:

   `pip install -r requirements_gofile.txt`

3. On Windows, double-click `Start_Gofile_Downloader.bat`.

Alternatively, launch the application with:

`python gofile_bulk.py`

## Usage

1. Paste a Gofile folder URL or ID.
2. Select Videos, Photos, or All Files.
3. Choose a download destination.
4. Preview the files or start downloading.

This project is an independent utility and is not affiliated with Gofile. Download only content you are authorized to access. Gofile API availability and authentication requirements may change.
